# Projeto Web ONG

## Apresentação do Projeto

Este projeto consiste no desenvolvimento de um site para uma ONG, com o objetivo de apresentar suas ações, projetos e formas de participação.

A aplicação foi desenvolvida buscando uma navegação simples, responsiva e acessível para diferentes tipos de usuários.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Vite

## Estrutura do Projeto

O projeto está organizado da seguinte forma:

- `html/` - páginas da aplicação
- `css/` - arquivos de estilização
- `js/` - funcionalidades e interações
- `imagens/` - recursos visuais utilizados no site

## Funcionalidades

- Navegação entre páginas
- Formulário de cadastro
- Validação de campos
- Modal de confirmação
- Layout responsivo
- Estados visuais de foco
- Recursos de acessibilidade

## Acessibilidade

O projeto considera práticas recomendadas pela WCAG 2.1, incluindo estrutura HTML semântica, navegação por teclado, identificação adequada dos campos de formulário e contraste entre texto e fundo.

## Otimização

Foram consideradas práticas de otimização dos arquivos HTML, CSS, JavaScript e imagens para reduzir o tamanho dos recursos e melhorar o carregamento da aplicação.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

O fluxo de desenvolvimento utiliza:

- `main` - versão estável
- `develop` - desenvolvimento contínuo
- `feature/` - desenvolvimento de novas funcionalidades

## Execução Local

Não é necessária a instalação de dependências para executar a versão original do projeto.

Após clonar o repositório, basta acessar a pasta `html` e abrir o arquivo `index.html` em um navegador.
